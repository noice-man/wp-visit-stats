# Changelog

## 1.0.9 — 2026-10-13

- Исправлено отображение автора во всплывающем окне обновлений: отображается автор из WordPress-заголовка плагина (или из проверенного релиза Hub).
- Обновлены русскоязычные описания изменений в readme.txt. Учет посетителей, сеансов, просмотров и целей не менялся.

## 1.0.8 — 2026-10-12

- Уточнено описание добровольной статистики установок для разработчика на ворд-пресс.рф: зачем собирается версия плагина и как помогает поддерживать обновления со старых выпусков.
- Отказ от статистики установок не влияет на получение новых версий.

## 1.0.7 — 2026-10-12

- Исправлена ручная проверка обновлений через WPR Update Hub: при явной проверке запрашиваются свежие метаданные, при фоновой сохраняется кеширование.


## 1.0.6 — 2026-10-12

- Добавлен собственный учёт целей с отдельной таблицей, отчётом, динамикой по дням и детализацией источников.
- Добавлено отключаемое зеркалирование вызовов JavaScript `ym(..., 'reachGoal', ...)`.
- Параметры Метрики не копируются; сохраняются только код цели, номер счётчика, путь страницы и существующие анонимные хеши посетителя/сеанса.
- Учитываются действующие настройки согласия, DNT, исключения ботов и срок хранения.
- Сохраняются прежняя схема просмотров и штатные обновления через WPR Update Hub.

## 1.0.5 — 2026-10-12

- Новый виджет «Источники трафика» с долей и числом сеансов для поисковых систем, социальных сетей, переходов с сайтов, рекламы, email, UTM-кампаний и прямых заходов.
- Детализация каналов по источникам: Яндекс, Google, ВКонтакте, Telegram и другие площадки/домены.
- Атрибуция по первому зарегистрированному просмотру сеанса, а не по рефереру каждого просмотра.
- Ретроспективная классификация накопленных событий по `ref_domain`, `utm_source` и `utm_medium`; миграция базы не требуется.
- Сохранена совместимость с WPR Update Hub SDK v2 и текущими настройками.
- Исправлено определение Яндекс Браузера: `YaBrowser/` больше не определяется как Chrome.
- Исправлено отображение переключателя автообновлений: локальная безопасная запись `no_update` в WordPress при отсутствии новой версии в Hub.


## 1.0.4 — 2026-10-12

- Миграция проверки обновлений на WPR Update Hub v1.1 и штатный WordPress Update URI.
- Добавлен SDK v2 с добровольной анонимной статистикой установок (по умолчанию выключена).

## 1.0.3 — 2026-10-12

- Добавлен фильтр «Сегодня» в отчёте.
- Добавлены подсказки с датой и значением на графике при наведении и с клавиатуры.
- Сбор статистики и структура базы данных не изменены.

## 1.0.2 — 2026-10-12

- Проверка обновлений через GitHub Releases (в v1.0.4 заменена WPR Update Hub).

## 1.0.1 — 2026-10-12

- Исправлены нулевые показатели в столбцах «Посетители» и «Просмотры» в списках записей, страниц и публичных CPT: подсчёт подгружается в момент вывода строк, если WP_Query не вызвал предварительную загрузку.
- Для ранее записанных событий с `post_id=0` цифры в таблице сопоставляются с постоянными URL материалов без двойного подсчёта уникальных посетителей.
- Новые события со старым/отсутствующим `post_id` привязываются по permalink на сервере; посторонний ID игнорируется.
- Историческая привязка постепенно восстанавливается при открытии списка материалов, от новых записей к старым, ограниченными пакетами.
- Добавлены regression-тесты отображения столбцов, сопоставления URL и восстановления исторических событий.

## 1.0.0 — 2026-10-11

- Первый релиз WP Visit Stats: first-party cookie, журнал просмотров в базе WordPress, отчёты и график.
- Три базовые метрики: посетители, сеансы и просмотры страниц.
- Расширенные данные визита: источник, UTM, устройство, браузер, материал.
- Сортируемые столбцы посещаемости для записей, страниц и публичных CPT.
- Настройки исключений, согласия и срока хранения; автоочистка через WP-Cron.
- Русскоязычная документация и интеграция с ворд-пресс.рф.
